桌面应用本就在一个环回端口上为自己的 WebView 运行后端——但把一个无认证后端直接放上局域网，等于把完整的 shell、文件与 agent 访问权拱手相让。**WebUI 远程访问**为此而生：一键在一个稳定的 LAN 端口额外绑定一个**经登录（密码 + 扫码）**的监听器，让你从手机或另一台浏览器使用 Nomi，而不放弃本地模式的便利。

它是**按实例启用**的，存在于你已运行的桌面应用内，与专用的 `nomifun-web` 部署不同。当你已有桌面安装、只想从同一网络的另一台设备访问时，用这个；需要长期无头部署时，用专用服务器。

![开放能力 WebUI 面板](/screenshots/webui-01-settings-overview.png)

## 架构：双监听器，一个后端

- **永久环回监听器**（随机端口）——桌面自己的 WebView，靠每启动密钥被信任，始终在线。
- **按需 LAN 监听器**（`0.0.0.0:25808`）——仅在你开启时绑定，远程浏览器连这个且必须登录。信任依据是**密钥**而非"来自 loopback"，因此同机其他账户、反向代理都不会被自动信任；还强制 Host/Origin 白名单（阻断 DNS-rebinding）并按对端地址限流。

## 操作步骤

1. **启用**。在"开放能力"（`/open-capabilities`）的 WebUI 面板点 Enable。后端在桌面进程内启动认证服务器（默认端口 `25808`），并开通管理员，**初始随机密码仅以明文显示一次**——请立即复制。
2. **拿到访问 URL**。显示的 URL 自适应：本机为 `http://localhost:<port>`，远程为 `http://<你的 LAN-IP>:<port>`。多网卡 / VPN 主机请确认广播的是手机真正可达的地址。
3. **手机扫码登录**。LAN 监听器运行时凭据卡会出现二维码。用手机扫码即在手机浏览器打开 `…/qr-login?token=<一次性>`。token **5 分钟过期**且一次性使用；UI 每 4 分钟自动刷新二维码。

   ![手机上的扫码登录](/screenshots/webui-04-qr-login-phone.png)

## 安全说明

- 服务器监听明文 HTTP，请仅在**可信本地网络**（家庭 Wi-Fi / VPN / Tailscale）使用；要超出此范围，请改用 TLS 反向代理后的 `nomifun-web`。
- 管理员拥有与本地桌面用户相同的能力（shell / 文件 / agent 执行），请妥善对待密码与 QR token——不要发布二维码截图。
- 修改密码会使所有现有会话失效（JWT 签名密钥随密码原子轮换）。
