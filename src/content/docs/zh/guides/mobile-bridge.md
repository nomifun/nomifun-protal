NomiFun Mobile 的定位是**手机远控入口**，不是把模型和完整桌面工作区复制到手机上。
手机把指令交给你自己的 NomiFun Desktop，由 Desktop 负责模型调用、会话执行和本地能力；
手机侧主要用于在离开电脑时查看状态、发起任务和处理需要确认的事项。

移动端项目仓库：
[nomifun/nomifun-mobile](https://github.com/nomifun/nomifun-mobile)。

## 当前适合做什么

移动端的轻量交互围绕以下场景设计：

- 查看已配对 Desktop 的会话列表、运行状态和最近结果摘要；
- 向已有会话发送指令，或发起一段新的任务；
- 接收任务完成反馈；
- 查看待确认的工具调用并确认或拒绝；
- 管理定时任务，包括新建、编辑、删除和立即执行。

手机端不直接调用模型，也不订阅完整的 thinking、工具调用和消息流过程数据，避免把
大量运行内容同步到手机。移动端保存的主要是配对配置、连接设置和少量近期事件摘要。

## 连接方式

### 局域网直连

在家庭或办公网络中，手机可以通过二维码或设备发现连接 Desktop 的轻量桥接端口。
这是最直接的路径：本地电脑就是服务端，数据不需要经过 NomiFun 云端账号或统一云服务。

### 跨网络连接

如果手机与电脑不在同一局域网，具体版本可能提供可选的公网中继方案。中继只负责撮合
连接和转发加密帧，手机与 Desktop 之间的业务载荷仍保持端到端加密；是否支持、如何部署
以及费用边界，以 Mobile 仓库当前说明为准。

因此，“手机直连 Desktop”主要指局域网和可信网络中的产品路径，并不等于所有跨网络
场景都必须完全不经过中继。

## 配对与安全

1. 在 Desktop 的远程桥接设置中生成一次性配对码和二维码。
2. 在手机端扫描二维码，或在没有摄像头时粘贴桥接串并输入配对码。
3. Desktop 验证配对码后保存已授权设备；不再信任的设备可以在 Desktop 中吊销。
4. 配对完成后，双方通过加密的 RPC 通道交换精简后的任务和结果数据。

配对码应视为登录凭据，不要把二维码公开发布。请只在可信网络中开启局域网桥接，并
保持电脑系统防火墙开启。

## 本地优先的边界

Mobile 不会替代 Desktop 的本地权限模型。真正执行命令、访问文件、调用模型和处理敏感
数据的仍是电脑上的 NomiFun；手机只是经过授权的控制面。启用中继、渠道或模型供应商
后，相关网络访问仍由你的配置决定。

移动端项目仍在快速演进，页面、支持平台、桥接协议和跨网络能力可能变化。请以
[NomiFun Mobile 仓库](https://github.com/nomifun/nomifun-mobile)和
[NomiFun Desktop 仓库](https://github.com/nomifun/nomifun-desktop)的当前版本为准。
