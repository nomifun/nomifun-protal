**设定**是一套可复用的会话启动配置。你可以把常用 Agent、模型、Skills、知识库、提示要求和适用场景放进同一条设定，下次创建会话时直接选择，不必重复配置。

入口在侧边栏 **设定**，也可以在首页输入框上方点“使用设定”。

![设定列表](/screenshots/presets-zh.png)

## 创建一条设定

1. 打开“设定”，点击新增。
2. 填写名称、简介和头像，帮助自己在列表中快速识别。
3. 选择主要 Agent 与候选模型。需要时可以允许回退到其它可用执行方式。
4. 添加这类工作默认需要的 Skills 与知识库。
5. 写入提示要求，例如角色、产出格式、工作约束和质量标准。
6. 添加受众与场景标签，决定它更适合谁、适合什么任务。
7. 保存后回到首页，点击“使用设定”即可一键套用。

## 三种来源

- **预置设定**：随 NomiFun 发布，内容只读，可以直接使用或复制后再修改。
- **扩展设定**：由已安装扩展提供，内容由扩展维护，可以查看并使用。
- **自定义设定**：由你创建，可完整编辑、复制、启用、停用或删除。

## 与 Skills 的关系

设定负责“把哪些能力组合起来”，Skills 负责“告诉 Agent 如何完成某类工作”。一个 Skill 可以被多条设定复用，修改技能库不需要把内容复制到每条设定中。

如果还没有合适的 Skill，可前往侧边栏“技能”：

- 在“已安装 Skills”中管理本地能力；
- 在“Skill Market”中浏览 ClawHub 与 SkillHub 榜单；
- 查看技能详情后，交给 Nomi 生成安装确认草稿。

## 使用建议

- 按真实工作流建立设定，例如“代码审查”“周报整理”“需求拆解”，比只按角色命名更容易复用。
- 把稳定规则放进设定，把每次变化的目标留在会话输入框。
- 先复制预置设定再修改，可保留原版作为对照。
- 长任务建议同时配置备用模型，避免单个模型暂时不可用时中断。
