**助手**是一套可复用的角色配置：它把展示信息、默认 agent 后端、可选模型偏好、system prompt 和技能选择打包成一个条目，让你在新建会话时一键选用，而不必每次重写提示词。

入口在 **`/assistants`**（旧路径 `/settings/assistants` 会重定向到 `/assistants?tab=assistants`）。同一页面的 **技能** tab 在 `/assistants?tab=skills`。

![助手列表（内置库）](/images/zh/助手&skill&mcp/助手列表.png)

## 操作步骤

1. **浏览助手库。** 打开 `/assistants`，列表把三类来源合并展示：**内置（Builtin）** 随应用预置、**自定义（Custom）** 由你创建、**扩展（Extension）** 由已安装扩展提供。每个条目都能启用/禁用、调整排序，列表也会记录最近使用，方便会话里快速挑选。

2. **新增助手。** 点新增，填写名称、描述与头像；选一个**默认 agent 后端**（如内置 `nomi`、或 `claude` / `codex` / `gemini`）；按需设置模型偏好；写好 **system prompt**（助手指令）；勾选启动会话时要附带的**技能**。保存后即可在会话里选用。

   ![新增 / 编辑助手](/images/zh/助手&skill&mcp/新增助手.png)

3. **编辑助手。** 自定义助手可完整编辑名称、描述、头像、prompt 与技能，也可删除。内置助手内容只读，但启用状态、排序、最近使用以及默认后端的覆盖可单独保存；扩展助手在本页只读，生命周期由扩展管理。

4. **用标签归类。** 在标签管理里建立标签并打到助手上，列表顶部即可按标签筛选——助手多起来时，这是最快的定位方式。

   ![标签管理](/images/zh/助手&skill&mcp/标签管理.png)

5. **在会话中选用。** 新建会话或在会话头部切换 agent 时挑一个助手，它的 prompt 与启用技能会在会话开始时自动生效。助手的技能会与自动注入的内置技能合并，正常使用无需手动复制技能目录。

## 要点与边界

- **三种来源、不同可编辑度。** 自定义助手可改可删；内置助手内容只读（仅启用/排序/默认后端覆盖可变）；扩展助手只读。
- **默认后端与 provider。** 创建助手时若未指定默认后端，需至少配置一个 provider，能推断时默认用内置 `nomi`。
- **CLI 型 agent 需自行安装。** 选 `claude` / `codex` / `gemini` 不会自动安装这些工具——它们仍需在宿主机预先装好对应 CLI。
- **技能按伙伴隔离，记忆全家共享。** 每个伙伴拥有专属技能库，而记忆走全体伙伴共享的一条采集/学习链路；按伙伴细分的私有记忆敬请期待。
- **技能与 MCP 分开管理。** 技能 tab 在 `/assistants?tab=skills`，MCP server 已独立到 `/mcp`，两者都能扩展能力但当前各自管理。

## 常见问题

- **助手和会话是什么关系？** 助手是“模板”，会话是“实例”。选定助手后，它的 prompt、默认后端与技能会成为该会话的起点；之后在会话里的临时调整不会改写助手本身。
- **内置助手能改吗？** 内容不能改，但可以启用/禁用、调整排序，并覆盖它的默认后端。想完整自定义时，新建一个自定义助手即可。
- **删除自定义助手会怎样？** 会一并清理它关联的规则、技能与头像文件。
