NomiFun 的数字伙伴从"单只 nomi"升级为**多伙伴家庭**：你可以创建多只伙伴并同时使用，分别命名、挑选形象、调校人格，每只伙伴可用自己的聊天模型、绑定自己的知识库，逐步演化出金融 / 文学 / coding / 情感等专业伙伴。本页讲清楚如何从零养成一只伙伴，以及背后两条关键的数据边界。

记忆模型是关键，请先记住这条边界：

- **共享记忆中枢（全家共享）**——采集与学习是一条全局链路，任何一只伙伴学到的、记住的东西，全家都记得。换一只伙伴继续聊，它知道之前发生的一切。
- **专属技能库（按伙伴隔离）**——每只伙伴养成自己的一套技能，互不串味。
- （按伙伴细分的**私有记忆**敬请期待。）

> 入口在侧边栏 **桌面伙伴** 页（`/nomi`）。任意桌宠窗口右键「打开聊天」也会深链到这里。

## 操作步骤

1. **新建伙伴**。点伙伴切换条上的「新建伙伴」，起个名字。第一只伙伴自动成为默认伙伴（默认形象 Mochi）——默认伙伴是渠道未显式绑定时的回退对象。

   ![新建伙伴](/images/zh/桌面伙伴/新增桌面伙伴.png)

2. **挑选形象**。从 3 款内置形象中选一个：**Mochi 麻薯兔**、**Ink 墨墨黑猫**、**Bolt 波特机器人**（均为纯代码绘制的 SVG，无需下载素材）。

   ![新增形象](/images/zh/桌面伙伴/新增形象.png)

3. **管理形象库**。形象库列出所有可用形象，含内置款与你自定义的款，可随时复用到任意伙伴。

   ![形象库](/images/zh/桌面伙伴/形象库列表.png)

4. **自定义任意 IP**。不止内置三款——你可以采集**任意 IP** 作为伙伴形象，甚至是你的家人或宠物，捏出一只独一无二的伙伴。

   ![自定义形象采集（任意 IP，甚至家人/宠物）](/images/zh/桌面伙伴/形象采集.png)

5. **调校这只伙伴**。在它的「设置」Tab 里随时改名（即时生效）、换形象、调人格（内置预设或**自由文本**自定义），并单独为它选聊天模型、开关桌宠与勿扰时段。

   ![伙伴设置：改名 / 换形象 / 调人格 / 选聊天模型](/images/zh/桌面伙伴/桌面伙伴设置.png)

6. **开始对话**。在该伙伴的「聊天」Tab 与它对话，这是它专属的陪伴会话线程。

   ![与伙伴对话](/images/zh/桌面伙伴/桌面伙伴聊天页.png)

7. **养成专属技能库**。每只伙伴拥有一套**按伙伴隔离**的技能库。进化引擎会从伙伴的**工具调用序列**中挖掘可复用的 skill（仅基于调用序列本身，**不含任何参数值**），生成草稿后你可以评审对应的 `SKILL.md` 再决定是否启用；养成的技能还能**赠予（gift）**给其它伙伴。

   ![专属技能库（按伙伴隔离）](/images/zh/桌面伙伴/桌面伙伴技能配置.png)

8. **绑定知识库**。在「模型 & 知识」Tab 为这只伙伴挂载一个或多个知识库——绑定按伙伴独立，对话时即可检索（详见[知识库](/zh/docs/guides/knowledge-base)）。给不同伙伴绑不同的库，就得到了「金融伙伴」「文学伙伴」「coding 伙伴」。

   ![为伙伴绑定知识库](/images/zh/桌面伙伴/桌面伙伴知识库配置.png)

9. **共享记忆互通**。在共享域可以手动新增一条共享记忆。在任意一只伙伴聊天里让它记住一件事，切换到另一只伙伴提问——它同样知道，因为记忆中枢是全家共享的。

   ![新增共享记忆](/images/zh/桌面伙伴/桌面伙伴新增共享记忆.png)

10. **配置数据采集**。共享数据采集决定哪些工作数据会被记忆中枢学习。多数采集项**默认关闭、需手动 opt-in**，你可以按类别精细控制。

    ![共享数据采集配置（多数默认关，opt-in）](/images/zh/桌面伙伴/桌面伙伴共享数据采集配置.png)

11. **换机迁移**。共享域的「迁移」Tab 提供三种 `.zip` 迁移包：**记忆包** / **伙伴包** / **知识库包**。换机时按 **知识库 → 伙伴 → 记忆** 的顺序导入即可平滑迁移（先有知识库，伙伴包里的绑定才能按名重建）。

    ![换机迁移（记忆 / 伙伴 / 知识库 .zip 包）](/images/zh/桌面伙伴/桌面伙伴共享记忆迁移.png)

12. **开启桌宠**。开启桌宠开关后，伙伴会拥有一个透明、置顶、可拖动的桌面窗口陪着你。

    ![开启桌宠（透明置顶桌面窗口）](/images/zh/桌面伙伴/开启桌面伙伴.png)

## 要点与边界

- **记忆共享，技能隔离**：所有伙伴共用一条采集 / 学习链路与同一份长期记忆；技能库则按伙伴独立养成。请不要把它理解为"每只伙伴各有一份私有记忆"——按伙伴细分的私有记忆是后续路线。
- **进化引擎只看序列、不看参数**：skill 挖掘仅基于工具调用的**序列**，不会记录调用参数值，因此沉淀出的技能可放心评审与共享。
- **桌宠同屏建议 ≤ 5 只**：每个桌宠窗口是独立 WebView，开太多会影响性能；UI 会提示但不硬性限制。
- **远程渠道按伙伴绑定**：每个 IM 平台可各绑一只伙伴来接待远程消息，未绑定时回退默认伙伴。绑定与改绑详见[渠道](/zh/docs/guides/channels)。

## 隐私边界

- **原始采集事件默认不导出**：`events` 原始数据包含你的工作内容原文，默认**不**进迁移包，只有显式勾选「包含原始事件数据」才会导出。
- **聊天历史不随伙伴包迁移**：伙伴包只带人格与设置，陪伴会话记录留在原机。
- **旧版自动迁移**：从单宠版本升级，首次启动会自动迁移为"共享记忆中枢 + 第一只伙伴"，无需任何手工操作。

## 常见问题

- **删了所有伙伴会丢记忆吗？** 不会。共享记忆中枢独立于伙伴存在，伙伴可以删到零个，采集 / 学习照常运行。
- **迁移后伙伴的模型没生效？** 模型配置随包带走，但若新机尚未配置对应 Provider，会显示未配置，到设置里重选即可。
