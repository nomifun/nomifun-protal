NomiFun 的数字伙伴从"单只 nomi"升级为**多伙伴家庭**：你可以创建多只伙伴并同时使用，分别命名、挑选形象、调校人格，每只伙伴可用自己的聊天模型、绑定自己的知识库（演化出金融 / 文学 / coding / 情感等专业伙伴）。

记忆模型是关键：**所有伙伴共享同一个记忆中枢**——采集与学习是一条全局链路，任何一只伙伴学到的东西全家都记得；而**技能库按伙伴隔离**——每只伙伴养成自己的专属技能。（按伙伴细分的私有记忆敬请期待。）

> 入口在侧边栏 **Nomi** 页（`/nomi`）。

## 操作步骤

1. **新建伙伴**。点伙伴切换条上的"新建伙伴"，起名、从 3 款内置形象（Mochi 麻薯兔 / Ink 墨墨黑猫 / Bolt 波特机器人）中挑一个，或自定义任意伙伴 IP（甚至你的家人、宠物）即可。第一只自动成为默认伙伴（默认 Mochi）。
2. **调校这只伙伴**。在它的"设置" Tab 改名、换形象、调人格（预设或自由文本），并单独为它选聊天模型、开关桌宠与勿扰时段。
3. **绑定知识库**。在"模型 & 知识" Tab 为它挂载一个或多个知识库，对话时即可检索（详见[知识库](/docs/guides/knowledge-base)）。
4. **共享记忆互通**。在一只伙伴的聊天里让它记住一件事，切换到另一只伙伴提问——它同样知道，因为记忆中枢是全家共享的。
5. **换机迁移**。共享域的"迁移" Tab 提供三种 `.zip` 迁移包（记忆包 / 伙伴包 / 知识库包）。新机按"知识库 → 伙伴 → 记忆"顺序导入即可平滑迁移。

## 桌宠与渠道

每只开了"桌宠"开关的伙伴拥有自己的透明置顶桌面窗口（建议同屏不超过 5 只）。每个 IM 平台可各绑一只伙伴来接待远程消息；未绑定时回退默认伙伴。详见[渠道](/docs/guides/channels)。

## 隐私边界

原始采集事件默认**不**导出，只有显式勾选才会进记忆包；聊天历史也不随伙伴包迁移。从单宠版本升级会在首次启动时自动迁移为"共享记忆中枢 + 第一只伙伴"，无需手工操作。
