## 本轮修正

用户走查指出初版舍弃了参考项目的大型图形动效。这一问题成立：普通入场、点云、简化卡片无法代表双波空间舞台、横向飞入、液态扩张与连续3D压栈。旧 `design-qa.md` 只作为初版内容记录，不能当作参考动效完整保留的证明。

本轮直接核查参考 React 组件、GSAP 行为、CSS 和两份 ix2 数据，再重建对应机制。75个提取事件并非75种效果，且其中53个指向旧节点；真实共享翻牌和磁吸事件还有遗漏。全部相关动效族的实现位置与原参数见 `motion-reference-inventory.md`。原品牌媒体、商业文案和追踪脚本没有进入新展示。

## 发现并修复的问题

1. 工作阶段dock与全局阅读dock重叠。上移工作dock，同步增加卡片底部操作空间，并保留低高度手机规则。
2. 伙伴650ms落牌动画锁吞掉手动点击。加入最后目标队列，手动选择暂停自动轮播，重新开始时重计3400ms。
3. 液态标签点击后立即闪回旧面板。导航中维持目标，完成或用户滚轮/触摸/纵向按键中断后恢复随滚动切换；过滤Lenis逐帧写入产生的过早scrollend。
4. 画廊切到图片后隐藏视频继续播放。切换时暂停非活动视频；滑动与指针跟随tween清理，增加30px单触点横向滑动并避开视频控制。
5. FAQ展开后缩窄窗口可能截断正文。展开动画结束设height:auto；桌面缩到390px后实际height/scrollHeight一致，内容完整。
6. 页面打开后修改减少动态效果，首屏与全局行为仍继续。新增媒体偏好hook，停止并清理Hero、Lenis、微动效、翻牌及相关舞台；已有场景的媒体监听保留。
