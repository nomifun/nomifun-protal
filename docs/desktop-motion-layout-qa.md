# 标准桌面动效与创作区修正

日期：2026-10-03。本轮修正前的旧版源码已随 Git 历史重建移除，修正前后截图仍保存在本文链接中。本轮对应用户提供的两处问题：工作卡片突然飞入，以及创作对话面板出现内层滚动条。验收使用浏览器的 CSS 视口 1920×1080、1440×900、1366×768、正常页面缩放；没有更改操作系统显示设置，也没有为当前非标准窗口新增适配规则。

## 工作卡片

原实现用 `.15 → .20` 的 5% 进度线性完成 45vw 横移、70vh 纵移、0.62 → 1 缩放和 6° 旋转。在 500vh 轨道上，三个标准视口的入场滚动距离仅约 216 / 180 / 154px。起止速度骤变，导航又按原始滚动进度更新，早于缓冲中的画面。

现在同一渲染时钟驱动首卡、侧卡、横轨、背景和阶段选择。首卡 `.04 → .24` 使用两端速度与加速度为零的平滑曲线，入场距离扩为约 864 / 720 / 614px；首卡落定后，横轨从 `.30` 开始。侧卡 `.18 → .30` 从屏外自然进入，没有透明度闪换。横轨两端平滑起停，中段匀速，逆向沿同一路径返回。卡片宽度、500vh 轨道、五阶段内容及手动/自动演示保留。

五个停靠点由同一变换函数反算：`.27 / .4708 / .605 / .7392 / .91`。尺寸刷新重新测量舞台与卡宽，不累积位移。浏览器实际矩阵也已检查：进度约 `.146` 时，首卡缩放约 `0.831`，旋转约 `2.67°`；落定后缩放 1、位移 0、旋转 0。实现使用显式 scaleX/scaleY，避免 GSAP quickSetter 的 scale 别名不能展开到两个轴。

## 创作区

原英文 Chat 在 1366×768 下，内容区 clientHeight 为 342px，scrollHeight 为 491px，输入区与免责声明被内层滚动承接。原因是放大正文后仍保留纵向标题、固定顶部/底部留白和 430px 的演示最小高度。

标准桌面的 Chat / Audio 现在采用左侧介绍与动态图形、右侧完整演示的并排布局。正文保持 15–17px，主要介绍 16px，真实控件 13px；通过空间重排和合理间距完整展示，没有整体缩放文字或裁掉内容。中文标题按语义短语换行，英文使用平衡换行。Image / Video 保持完整 contain 展示及素材版本说明；Canvas 使用三列节点，添加音频后为四列，端口连线随真实布局重新计算。

桌面内容区不拦截页面滚动；只有既有可滚动后备布局确实溢出时，才设置 Lenis 防拦截属性。全屏工作/创作舞台反向滚动时，顶栏也保持收起，避免盖住顶部内容；底部目录仍可操作，打开和关闭目录后正确恢复。
